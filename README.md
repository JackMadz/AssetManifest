# AI-Asset Manifest Packer 🧩🤖

> Утилита на чистой Java 26 для автоматической генерации семантического контекста графики под ИИ-агентов и LLM.

Забудь про ручное описание спрайтов и трату токенов на передачу тяжелых картинок мультимодальным моделям. Инструмент сканирует папку со спрайтами, анализирует их пиксели и создает **`AI_ASSETS_CONTEXT.md`** — текстовый паспорт графики с размерами, цветами и **ASCII-превью**.

---

## 🚀 Быстрый старт (без сборщиков и зависимостей)

Требуется установленный **JDK 26**.

1. Положи скрипт `Main.java` в корень проекта.
2. Создай рядом папку `sprites` и закинь туда свои `.png` файлы.
3. Запусти скрипт напрямую через интерпретатор Java:
   ```bash
   java Main.java
